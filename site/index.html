Installation & Platform Notes

Select your platform to view package targets, required permissions, and quick setup commands.

macOS 14.2+ (Apple Silicon & Intel)

Download TouchBarLyrics-2.4.0-macOS.zip from GitHub Releases, extract TouchBarLyrics.app, and drag it into /Applications or ~/Applications.

  1. Gatekeeper note: Local/CI builds use ad-hoc signing by default. If macOS says the app cannot be verified on first launch, right-click TouchBarLyrics.app and choose Open, or clear the quarantine attribute in Terminal: 
xattr -cr /Applications/TouchBarLyrics.app
  1. System Audio Recording permission: When prompted, allow System Audio Recording so the lock-free CoreAudio vDSP engine can align vocal timing and pitch lift. Declining still works via timestamp playback.
  2. Build from source: Run tests and install locally without Xcode using Swift CLI: 
./tests/run.sh && ./build.sh --install

Windows 10 / 11 (x64 & ARM64)

Uses built-in PowerShell WinRT GlobalSystemMediaTransportControls (win_smtc.ps1) with zero C++ build tools or external media drivers.

  1. Install or run portable: Launch NotchLyrics Setup 2.4.0.exe (dual-arch installer) or run the architecture-specific portable executable directly.
  2. System Tray controls: Right-click the NotchLyrics tray icon to switch Notch styles, toggle Romanization, run Refetch Lyrics (Clear Cache), nudge Manual Lyrics Offset (±0.1s / ±0.5s), or change UI language.
  3. Run or build from source: 
cd windows && npm install && npm test && npm start

Linux Desktop (X11 & Wayland, x64)

NotchLyrics listens to org.mpris.MediaPlayer2.* via playerctl --follow and falls back automatically to gdbus or dbus-send polling if playerctl is absent.

  1. Install playerctl (recommended for lowest CPU): 
# Debian / Ubuntu / Mint
sudo apt update && sudo apt install playerctl

# Arch / Manjaro
sudo pacman -S playerctl

# Fedora
sudo dnf install playerctl
  1. Run AppImage or install .deb package: 
chmod +x NotchLyrics-2.4.0.AppImage && ./NotchLyrics-2.4.0.AppImage
# or on Debian / Ubuntu:
sudo apt install ./notchlyrics-windows_2.4.0_amd64.deb

Zero-Build Browser Extension (Chrome / Edge / Brave)

Run the Golden Ratio OLED Notch directly inside Chromium-based browsers with no Node.js runtime or desktop installer required.

  1. Clone or download the repository and locate windows/browser-extension.
  2. Open chrome://extensions (or edge://extensions / brave://extensions).
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select the windows/browser-extension directory.

Supported Web Players

  • Spotify Web (open.spotify.com)
  • SoundCloud & Apple Music Web
